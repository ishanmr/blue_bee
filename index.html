Architecture & Stack Reference

Bluebee Gucci-Style Website File Structure

For instant interactive preview in Canvas, all modules are compiled into a single self-contained bundle (bluebee_storefront.html). When deploying as a multi-file production repository, the project splits cleanly into the following directory tree: 

bluebee-maison-storefront/
├── index.html                  # Main entry shell (Gucci header + Category-only Home)
├── assets/
│   └── images/
│       ├── hero-aw26-campaign.jpg
│       ├── cat-hoodies-520gsm.jpg
│       ├── cat-baggy-cargos.jpg
│       ├── cat-varsity-outerwear.jpg
│       ├── cat-boxy-tees-knits.jpg
│       └── cat-preloved-sashiko.jpg
├── styles/
│   ├── tailwind.config.js      # Bluebee Royal Cobalt (#02419F) & Tan Nimbus, Obsidian & Serif tokens
│   └── maison.css              # Gucci wordmark tracking, web stripe & animations
└── src/
    ├── data/
    │   └── products.js         # 8-piece USD ($) streetwear & archive catalog
    ├── components/
    │   ├── categoryShowcase.js # Category-only homepage router (no main-page products)
    │   ├── showroomGrid.js     # Filtered category product grid + quick-view modal
    │   ├── cartDrawer.js       # Slide-out bag + 3-tier reward progress bar
    │   └── fitStudio.js        # Boxy/baggy proportion calculator & trade-in tool
    └── main.js                 # View state manager & event delegation
